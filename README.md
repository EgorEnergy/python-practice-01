# Практическая работа 1. Консольное приложение на Python

## Назначение проекта
Учебный проект по дисциплине «Практика». Реализует 4 консольных
приложения в одном файле с общим меню:
калькулятор, конвертер единиц, анализатор числа, расчёт стоимости покупки.

## Какие задачи решает программа
1. Консольный калькулятор (+, -, *, /, //, %, ^)
2. Конвертер единиц (C→F, км→мили, кг→фунты, м→футы)
3. Проверка характеристик целого числа (знак, чётность, делимость, простота, разрядность)
4. Расчёт стоимости покупки со скидкой (5% / 10% / 15%)


## Инструкция по запуску
1. Установить Python 3.10+
2. Скачать файл `main.py`
3. Открыть терминал в папке с файлом
4. Выполнить:
   python main.py


## Как пользоваться программой
После запуска выводится главное меню с выбором варианта (1–4).
Внутри каждого варианта — свой интерфейс и подсказки.
Для выхода введите 0.

## Пример работы
=== ПРАКТИЧЕСКАЯ РАБОТА 1 ===
1 - Вариант 1. Консольный калькулятор
...
Выбери вариант: 1
Введите первое число: 15
Введите операцию (+, -, *, /, //, %, ^): *
Введите второе число: 4
Результат: 60
